# Агент управления проектом

Этот агент предназначен для помощи в управлении задачами проекта, подведении итогов выполнения работ и координации отслеживания проблем (issues) в репозитории.

## Использование

Здесь описываются поведение агента и способы его запуска. Например, рабочий процесс GitHub Actions или внешняя система автоматизации могут использовать этот файл в качестве основы для определения роли и обязанностей агента.

## Обязанности

- Отслеживание открытых проблем (issues) и контрольных точек (milestones)
- Обобщение информации о статусе задач и препятствиях (блокерах)
- Предложение дальнейших шагов для продвижения проекта
- Помощь в ведении проектной документации и организации бэклога

## Примечания

- В данном репозитории на текущий момент не настроена среда выполнения для агента.
- Представленные здесь файлы носят информационный характер; их можно адаптировать для использования в рабочих процессах, ботах или системах внешней автоматизации.
