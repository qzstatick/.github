Создать issue в qzstatick/.github

Заполните форму ниже — после отправки откроется страница создания issue на GitHub с предзаполненными полями.

Форма не хранит никаких данных и не использует токены. Issue будет создаваться от вашего аккаунта GitHub.

Если нужно автоматическое создание issue от имени сервиса — напишите, добавлю backend-решение.
