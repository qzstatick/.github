Создать issue в qzstatick/.github

Заполните форму и выберите способ создания issue: открыть страницу GitHub или автоматически создать через сервер (требуется деплой backend и секрет).

Форма не хранит данных. Автоматическое создание работает только если настроен backend-эндпоинт (см. README) и отправка проходит с корректным секретом.

Если нужно — помогу задеплоить backend (Netlify/Vercel) и настроить секреты.
